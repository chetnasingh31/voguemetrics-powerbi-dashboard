📊 VogueMetrics – Fashion Retail Analytics Dashboard
This project is a Power BI dashboard built to analyze Myntra fashion retail data and extract meaningful business insights related to product distribution, pricing strategies, brand performance, and customer engagement.

🎯 Objective
1) To transform raw e-commerce product data into actionable insights for understanding:
2) Product pricing structure
3) Discount strategies
4) Brand performance
5) Customer engagement patterns

🛠 Tools Used
1) Power BI
2) DAX (Data Analysis Expressions)
3) Data Cleaning & Transformation
4) Kaggle Dataset

📌 Key Insights
1) Topwear and fashion categories dominate product listings
2) Premium brands tend to maintain higher ratings with lower dependency on discounts
3) Mid-range price segments receive the highest discount allocation
4) Significant variation observed in brand performance across categories

📊 Dashboard Features
1) KPI overview (Products, Discounts, Ratings)
2) Price distribution analysis across segments
3) Top-performing brand analysis
4) Category-wise segmentation
5) Interactive filters (Category, Gender, Brand)
